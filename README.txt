Telegram Shop Bot

1. Install Python 3.9+.
2. pip install -r requirements.txt
3. Rename .env.example to .env
4. Put your bot token in TELEGRAM_TOKEN.
5. Put your Telegram numeric user ID in OWNER_IDS.
6. Run: python main.py

The bot creates database.json automatically.

User menu:
- ❤️ Autolikes
- 🏆 Guild Glory Bot
- 🛒 Purchase ID
- 📦 My Orders
- ❓ Help & Support

Payments use a generated UPI QR for the configured UPI ID. Payment approval is manual through the admin panel; no external payment API is used.
